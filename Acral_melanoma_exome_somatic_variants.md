# Acral melanoma exomes' analysis
# Variant Calling and driver gene identification 
## Author: Patricia Basurto Lozada


This file contains the variant calling strategy used for the mexican acral melanoma samples, as well as the code used for driver gene identificaton and for the generation of the plots included in the paper.  

Reference genome used: GRCh38

Reads were aligned to the GRCh38 reference genome with BWA-MEM (v0.7.17) and marked for duplicates with samtools (v1.14). 

SNV calling was done using three different tools (CaVEMan, MuTect2 and Varscan2). Varscan2 was used following the respective documentation recomendations (Koboldt et al., 2014). Mutect2 was used using a panel of normals created with all normal samples available from the patients for this cohort and following GATK recommendations. CaVEMan (v1.15.2) was run at the Wellcome Sanger Institute through a standardized pipeline. SNVs that were identified by at least two of these tools were used for further analysis.

Indels were identified using pindel (v.3.10.0), which was run as well at the Wellcome Sanger Institute through a standardized pipeline. 


# Driver gene identification

Driver gene identification was performed using the tool dndscv using only unique events (snv and indels) per patient as input data (mutations present in different samples from same patients were reported only once). Genes were considered to be driver genes when q-values estimated by dndscv were below 0.1. 

Input data for dndscv was generated by concatanating variants from all samples and eliminating duplicates (same mutations from related samples, such as samples from the same patient), adding indels identified by pindel and manually annotating dinucleotide variants if necessary (after confirming they are the same event using IGV) following dndscv recommendations. 



``` R
#Loading library
library(dndscv)
#Reading input data
acral_data <- read.csv("/data/somatic_variants/dndscv_input_table.csv", header=TRUE, sep='\t')
#Running dndscv
dndsout = dndscv(acral_data, refdb = "RefCDS_human_GRCh38_GencodeV18_recommended.rda", cv=NULL)
#Showing significant genes
sel_cv = dndsout$sel_cv
signif_genes = sel_cv[sel_cv$qglobal_cv<0.1, c("gene_name","qglobal_cv")]
rownames(signif_genes) = NULL
print(signif_genes)
 gene_name   qglobal_cv
1      NRAS 0.000000e+00
2       KIT 4.970833e-10
3      BRAF 3.864335e-07
4       NF1 1.122492e-04

## Writing output with selection coefficients and q values
write.csv(sel_cv, 'sel_cv.csv', row.names=FALSE)

```
# Visualization of mutational profile as an oncoplot (Figure 1a)

Visualization of the mutational profile was done generating an oncoplot using the R package maftools. One sample per patient was used, giving preference to primary tumours when available. Genes showed were selected based on dndscv results. 

``` R
library(maftools)
library(RColorBrewer)
#Reading MAF ans cn data 
# MAF with data from one sample per patient <- Per_patient_MAF_maftools.maf (This file was generated using maftools after merging individual MAFs of one sample per patient, both snv and indel MAFs)

per_patient <- "data/somatic_variants/Per_patient_MAF_maftools.maf"
all_alt_cn = read.maf(maf=per_patient, cnTable=nf1_cn_data )
#Reading file containing clinical data
clindata = read.csv("data/Supplementary_Table_1.csv", sep=",", header=TRUE)

#Plotting oncoplot with tumor location annotation

clincolors = RColorBrewer::brewer.pal(n = 4,name = 'Accent')
names(clincolors) = c("foot", "hand", "subungual")
clincolors = list(Primary_tumour_site = clincolors)
oncoplot(all_alt_cn, draw_titv = TRUE, annotationDat=clindata, showTumorSampleBarcodes=TRUE, annotationColor = clincolors, genes = c("NRAS","BRAF","KIT","NF1","HRAS", "SPRED1", "TP53"), clinicalFeatures= c("Primary_tumour_site"), bgCol="white")
```

# Important Notes

CaVEMan calls identified 2 samples with BRAF V600 mutations that were not identified in the final call set of the 2 outof3 strategy. BRAF variants in these samples were lost in our callset as in one case (PD40987a) the variant was only identified by one the variant callers (MuTect with an allele depth of 10 for the reference vs 3 for the alternative; a depth of 13 and a allele fraction of 0.231) and in the other case (PD51930a) the variant was identified by Mutect2 but these variants were filtered out due to the depth of the site ( allele depth 3 for the reference and 3 for the alternative, a depth of 6 an allele fraction of 0.5). These variants were visualized using IGV, considering the previous knowledge about the oncogenicity of these mutations these were included in the final call set. 

Patient PD40987 had another sample (PD40987d) that had no BRAF variants identified by any tool but was manually inspected in IGV showing evidence of the mutation. We considered this sample as BRAF mutated for follow up analysis even though this is not reported in MAF files. In a similar way sample PD51928d (Lymph node metastasis) was annotated as not having a mutation in NRAS by variant calling tools, although there are reads supporting a mutation in this gene, due to this mutation being annotated as normal artefact. Normal adjacent tissue, which was used as normal, had presence of this same mutation in several reads. We also considered this sample as NRAS mutated in follow up analyses, although this is not reflected in MAF files. 

Samples PD41923g, PD41913e, PD51969d, PD51928a, PD41029e and PD41896a underwent variant calling using two different normal samples (same patient, different tissues) as reflected on final maf files.
