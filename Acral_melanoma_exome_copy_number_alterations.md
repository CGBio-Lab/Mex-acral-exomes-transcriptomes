## Copy number calling

Estimation of copy number, ploidy and cellularity was done using SEQUENZA and ASCAT. We compared purity estimates between ASCAT and Sequenza and dropped samples that had a high discrepancy between the two tools (purity of 1 vs a purity less of 0.15). After this we filtered out samples that had a Goodness of fit estimate from ASCAT analysis below 95. A total of 60 samples (47 patients) passed filteres. We then proceeded to use ASCAT outputs from these samples for follow up analyses. 

To identify significant regions altered by copy number alteration we used the tool GISTIC2 using as input one sample per patient (giving preference to primary tumors when available).

## Identifying significant peaks with GISTIC2 

We generated GISTIC2 input file using ASCAT segmentation data outputs and formatting as instructed in GISTIC2 documentation. 

 
``` bash
#input data ascat_per_patient_24april_gistic_input.txt 
#!/bin/sh
unset DISPLAY
## output directory
echo --- creating output directory ---
basedir=`pwd`/ASCAT_acrals_hg38_one_per_patient_95ci
mkdir -p $basedir 

echo --- running GISTIC ---
## input file definitions
segfile=`pwd`/data/copy_number_alterations/ascat_per_patient_gistic_input.txt
refgenefile=`pwd`/refgenefiles/hg38.UCSC.add_miR.160920.refgene.mat

## call script that sets MCR environment and calls GISTIC executable 
./gistic2 -b $basedir -seg $segfile  -refgene $refgenefile -conf 0.95 -qvt 0.1 -ta 0.25 -td 0.25 -genegistic 1 -savegene 1  

##-alf $alf 

##-cnv $cnvfile -genegistic 1 -smallmem 1 -broad 1 -brlen 0.5 -conf 0.90 -armpeel 1 -savegene 1 -gcm extreme

```

# Plotting barplot of burden of alterations in GISTIC significant peaks by sample (Supplementary Figure 5)

``` python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
from matplotlib import pyplot


#Reading file with significant regions 
signif_regions = pd.read_csv("/data/copy_number_alterations/all_lesions.conf_95.txt", sep="\t")

#Filtering out rows with CN values
filtered_signif_regions = signif_regions[~signif_regions['Unique Name'].str.contains('CN', na=False)]
#Filtering columns with all NA values
filter2_signif_regions = filtered_signif_regions.dropna(axis=1, how='all')

#Separating amplification and deletions peaks
amplification_peaks = filter2_signif_regions[filtered_signif_regions.astype(str).apply(lambda row: row.str.contains("Amplification", na=False)).any(axis=1)]
deletion_peaks = filter2_signif_regions[filtered_signif_regions.astype(str).apply(lambda row: row.str.contains("Deletion", na=False)).any(axis=1)]
# Count non-zero values per column (number of regions altered per sample) for amplifications
non_zero_counts_Amp = (amplification_peaks.iloc[:, 9:] != 0).sum().reset_index()
non_zero_counts_Amp.columns = ['Tumor_Sample_Barcode', 'Count_Amp']
# Count non-zero values per column (number of regions altered per sample) for deletions
non_zero_counts_Del = (deletion_peaks.iloc[:, 9:] != 0).sum().reset_index()
non_zero_counts_Del.columns = ['Tumor_Sample_Barcode', 'Count_Del']
#Merging in one dataframe data for amplifications and deletions
amp_del_counts = non_zero_counts_Amp.merge(non_zero_counts_Del, how="outer", on="Tumor_Sample_Barcode")
#Creating a new columnn with negative counts for deletions (for plotting purposes)
amp_del_counts["Plot_count_del"] = ( 0 - amp_del_counts["Count_Del"])
#Raeding sample order (this file has the sample order shown in the GISTIC significant peaks oncoplot)
sample_order = pd.read_csv("data/copy_number_alterations/Sample_order_barplot.txt")
#Ordering the dataframe by the sample order
ordered_amp_del_counts = sample_order.merge(amp_del_counts, how="left", on="Tumor_Sample_Barcode")

#Plotting the barplot
fig = plt.figure(figsize=(20, 9))
ax = plt.subplot(111)
ax.bar(ordered_amp_del_counts["Tumor_Sample_Barcode"], ordered_amp_del_counts["Count_Amp"], width=1, color='r')
ax.bar(ordered_amp_del_counts["Tumor_Sample_Barcode"], ordered_amp_del_counts["Plot_count_del"], width=1, color='b')
plt.xticks(rotation=90)
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['bottom'].set_visible(False)
ax.spines['left'].set_visible(False)


```
# Generating CN Heatmap (Figure 2b)

Data for the heatmap (average segment means per chromosome arm) as well as copy number scores (GCS = global copy number scores, FCS = focal copy number scores and BCS = broad copy number scores) were obtained from the web application CNApp using as input ASCAT segmentation and copy number estimations where segment means (seg.mean) were calculated as log2(cn/ploidy), and using default values. 

Average segment mean values by chromosome arms were used to plot the heatmap. Samples were ordered based on mutational status. 

``` python
#Reading file ordered by mutational status
cn_data = pd.read_csv("data/copy_number_alterations/cna_profile_Arms_by_mutation_status.csv", sep=",", index_col=0)
sns.set(rc={'figure.figsize':(30,15)})
#Plotting hetamap
sns.heatmap(cn_data, center=0, cmap="bwr", robust=True)
```
